Responsabilidad del módulo:
Este módulo se encarga de iniciar la ejecución principal del software de fuerza bruta Wifite. Tiene la responsabilidad de leer y interpretar argumentos de línea de comandos, inicializar la estructura de estado del software, y ejecutar el principio del proceso de fuerza bruta.

Funciones/clases principales:
En este módulo se encuentran principalmente las funciones start() y main(). La función start() inicia la ejecución principal del software, mientras que main() es la función principal que lee los argumentos de línea de comandos y llama a start().

Dependencias:
Este módulo depende de otros módulos para su correcto funcionamiento. Específicamente, depende de wifite.c para definir la estructura wstate y de utils.c para definir las funciones str2mac() y usage().
