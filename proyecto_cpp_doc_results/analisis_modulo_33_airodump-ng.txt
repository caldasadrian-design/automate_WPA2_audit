Responsabilidad del módulo:
Este módulo se encarga de la recolección y análisis de datos de redes inalámbricas. Tiene la responsabilidad de capturar paquetes de red, analizarlos y registrar la información relevante en una base de datos.

Funciones/clases principales:
Las principales funciones/clases del módulo son:
- `main`: Función principal que inicia el proceso de recolección y análisis de datos.
- `init_term`: Función que inicializa el manejo de la terminal.
- `capture`: Función que captura los paquetes de red y los pasa al análisis.
- `analyse`: Función que analiza los paquetes de red y los registra en la base de datos.
- `parse_options`: Función que analiza las opciones de línea de comandos proporcionadas.

Dependencias:
Este módulo depende de los siguientes módulos:
- `airmon-ng`: Módulo para activar o desactivar la interfaz de red en modo monitor.
- `aireplay-ng`: Módulo para realizar ataques de tipo de intercepción de credenciales.
- `mdk3`: Módulo para realizar ataques de tipo de denegación de servicio.
- `hostapd`: Módulo para simular un AP de acceso inalámbrico.

Problemas identificados:
1. Falta de soporte para la captura de paquetes de red en Linux.
2. La interfaz de red debe estar en modo monitor para recolectar los paquetes.
3. La recolección de datos puede no ser confiable debido a problemas de seguridad.
