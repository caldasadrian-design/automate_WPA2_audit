3. Dependencias: El archivo principal "main.c" depende de otros archivos para funcionar correctamente. Estos archivos son:
- "common.h": contiene las declaraciones de las funciones comunes, como `sql_stdout`, `print_help`, `check_for_db` y `print_stats`.
- "export.c": contiene las funciones para exportar la base de datos a diferentes formatos, como `export_cowpatty` y `export_ascii`.
- "import.c": contiene las funciones para importar datos en diferentes formatos, como `import_cowpatty` y `import_ascii`.
